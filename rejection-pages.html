Callback rejection pages

Rendered 2026-10-18 12:42:29Z from renderCallbackRejection, the same renderer the browser receives — not a copy.

These pages appear only when a sign-in is refused. A working sign-in never shows one, which is why only some of them can be reached by hand: the trigger below says which.

rejectNone

Anything Tantu cannot classify. Should be unreachable now that every check returns a typed rejection.
not reachable by hand · rejectNone · HTTP 400

rejectMethod

The application redirects with something other than a page navigation. Needs an application that does this.
not reachable by hand · rejectMethod · HTTP 400

rejectNotLoopback

The sign-in redirects to a host that is not this machine. Needs a misconfigured application.
not reachable by hand · rejectNotLoopback · HTTP 400

rejectNotNavigation

The sign-in page fetches the callback address instead of the browser following a redirect to it. Needs an application that redirects in script.
not reachable by hand · rejectNotNavigation · HTTP 400

rejectSubresource

The callback address is requested as an image, script or stylesheet. Needs an application that does this.
not reachable by hand · rejectSubresource · HTTP 400

rejectOriginUnknown

The callback carries an Origin and the sign-in's origin is unknown to Tantu. Needs an unusual redirect_uri.
not reachable by hand · rejectOriginUnknown · HTTP 400

rejectOriginMismatch

The callback comes from a different site than the sign-in started on. Needs a cross-site redirect chain.
not reachable by hand · rejectOriginMismatch · HTTP 400

rejectPath

The callback arrives on a path the sign-in did not register. Needs an application whose listener and registration disagree.
not reachable by hand · rejectPath · HTTP 400

rejectState

A sign-in is cancelled or superseded, then completed. **A person can do this**: start a sign-in, cancel it, then finish it in the browser.
reachable by hand · rejectState · HTTP 400

rejectBodyUnreadable

The callback body cannot be read. Needs the connection to break mid-request.
not reachable by hand · rejectBodyUnreadable · HTTP 400

rejectBodyTooLarge

The callback carries more than 1 MiB. Needs an application returning a very large response.
not reachable by hand · rejectBodyTooLarge · HTTP 413

rejectDuplicate

The callback URL is opened twice. **A person can do this**: reload the callback page.
reachable by hand · rejectDuplicate · HTTP 409

2 of 12 can be reached by an action a person takes. The rest need the application, the network or the browser to misbehave in a specific way, so the only evidence they have is constructed, not observed.
